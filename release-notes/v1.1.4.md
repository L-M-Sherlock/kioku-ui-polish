## What's new

- Added a touch-accessible Columns button and View menu item in the card browser, using Anki's existing column selector.
- Added Undo and More buttons to the review toolbar. More opens Anki's existing card actions, including flags, bury, suspend, and audio controls.
- Fixed a case where toolbar Undo completed but the reviewer stayed dimmed and did not refresh because of a focus-related deferral.
- Increased deck-list expand and options hit areas and improved spacing for five-digit counts in narrow windows.
