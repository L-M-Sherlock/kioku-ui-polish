## What's new

- Introduced a touch-friendly deck list with larger rows, expandable deck trees, colored counts, and a separate deck options button.
- Added larger, color-coded review buttons for two-, three-, and four-button layouts, preserving optional review intervals.
- Added a neutral Show Answer button with readable card counts in light and dark modes.
- Kept the installation ID of the earlier Kioku Touch Review Buttons add-on so this version can replace it.
